ScriptEd 1.50-beta Build 9

- Fixed Quest Editor to properly handle quests that exist in the master list (gamequest)
  but not in the smart/dumb quest logs (gamequestlog, GameQuestLogDumb). Previously,
  selecting such a quest would show wrong or blank data because the code used the listbox
  index as a direct array index into the quest logs. All lookups now use the proper
  GetMesIndexByID(gamequest.entries[ItemIndex].index, logfile) helper to translate the
  quest ID to the correct log array index. (forum #44)

- Fixed Dialogue Editor to skip blank lines during loading. Lines like
  {N}{}{}{}{}{}{} (no NPC text in any field) are no longer interpreted as
  dialogue nodes. The Dialogue Editor now also has a "Remove blank nodes"
  button that can strip pre-existing blank nodes from a loaded dialogue. (forum #41)

- Fixed Verbose Debug toggle in Preferences not taking effect. The checkbox was
  flipping a global in ScriptEdConfig.pas but the script compiler (ArcanumSCRLib.pas)
  reads a different global of the same name. The two are now kept in sync whenever
  the config is loaded or saved. (forum #37)

- Added "Create Nodes & Options" button to the Dialogue Generator (Player Options tab).
  Generates 3 player options with implicit node links (=> NODE:<name>) and creates the
  corresponding dialogue nodes in the currently selected node, wiring up linktonode
  pointers automatically. Requires a node to be selected in the dialogue editor first.

- Replaced TMS TAdvSmoothSplashScreen with native VCL splash screen (SplashScreenForm).
  Third-party AdvSmoothSplashScreen dependency removed from ScriptEd.dpr and ScriptEdWindow.dfm/pas.
  Splash image loaded from SplashIMG.png in EXE directory, with status label and progress bar.

- ConsoleDebug() status messages now routed to the native splash screen via ArcanumSCRLib.SplashStatusProc
  callback, replacing TMS TSplashListItem-based SplashMessage() implementation.

- Added a Dialogue Code Editor (ActionsEditor.pas/.dfm, uses DialogueOpCodes.pas) for composing
  the {Test} and {Result} fields on PC and NPC dialog lines. Provides a reference list of all
  2-letter Arcanum dialogue codes (ps, qu, gv, lc, wa, etc.) with descriptions and parameter
  counts, plus Insert (append) / Replace (overwrite) actions. Wired into:
    * Player Option Editor "Conditions" field (Test codes)
    * Player Option Editor "Actions" field (Result codes)
    * Dialogue Editor "Node actions" field (Result codes)
  The original TForm28 placeholder form was upgraded to host the new editor; the public unit
  name is unchanged for backward compatibility.

ScriptEd 1.50-stable Build 8

- Added Dialogue Generator accessible via Script > "Dialogue Generator..." menu or toolbar button.
  Provides a tabbed interface with three generation modes:
    * NPC Response: Generates in-character NPC replies given a description/role and player dialogue.
    * Player Options: Generates 3 concise player dialogue options from a context string.
    * Journal Entry: Generates journal entries with optional smart/detailed or simple/dumb tone.
  Includes copy-to-clipboard buttons for all result fields.
  Requires Ollama to be enabled and configured in Preferences.

- Added support for generating text with Ollama. Automatically detects if the server is running. 
You'll need to install Ollama from https://ollama.com/ and then pull some models from command line 
by using "ollama pull <modelname>", you can find all available models at https://ollama.com/search. 
These will be automatically detected by ScriptEd.
  AI Support currently enabled for generating npc responses, player options and journal entries. 
More AI enhancements will be added later.
 Also note: The performance of the AI text generation depends on your hardware (CPU, GPU, Memory) 
and how many parameters the model has, so it might take a while for the Ollama server to generate 
 a response. On my setup (Ryzen 5600X & GTX 1070 + 16gb of DDR4 RAM), it takes around 30 seconds
 up to one minute to generate text with mistral:7b. The <7B parameter models are much faster
and more suitable for rapid dialogue creation.
 
- Rewrote and optimized some of the script compiler code with some help from ChatGPT.
  The special case transform Attachee into basic prototype (num) was broken but was eventually
  fixed after a bit of debugging. Same goes for have (obj) try to steal 100 coins from (obj), this
  had problems compiling but now it should work fine.

- Flags are now set properly in the ScriptEd GUI version of the compiler.

- Fixed command line script compiler code to properly store flags when specified (Scripted
  will set the flags from the properties so they are already set when the script is compiled)

- Command line script compiler now passes the compilation of all official scripts.

- Command line script compiler updated with the new ArcanumSCRLib code.

- Added hints to various sections of the dialogue editor

- Updated app icon to a new one generated with DALL-E 3 through ChatGPT

- Dialogue Editor window enhancements: Added the npc text and player options to the tree view so they 
  are visible at all times. Also changed the treeview to a HTML formatted component. When you edit either 
  NPC text or player options, these items are updated as well.
  NOTE: they are for display only, you cannot edit them from the tree nodes directly.
